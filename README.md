# 📚 Book Management System

A simple **Book Management System** built using **Spring Boot, Spring Data JPA, Thymeleaf & H2 Database**.

---

## ✅ Features
- Add new Books 📖  
- View Book List 👀  
- Edit Book Details ✏️  
- Delete Books ❌  
- Simple UI using Thymeleaf 🎨  

---

## 🛠️ Tech Stack
| Technology | Description |
|-----------|------------|
| Java | Programming Language |
| Spring Boot | Backend Framework |
| Spring Data JPA | ORM | 
| H2 Database | In-Memory Database |
| Thymeleaf | Frontend Template Engine |
| HTML/CSS | UI Design |

---

## ▶️ How to Run Project

### 1️⃣ Clone Repository
git clone https://github.com/dharmarajpawar2487-lang/Book-Management-System.git
 

### 2️⃣ Open in STS / IntelliJ / VS Code

### 3️⃣ Run Spring Boot App
mvn spring-boot:run
------

### 4️⃣ Open Browser
http://localhost:8080
